# Public registration QR

Status: **intentionally deferred during local development at the owner's request**. Public registration QR generation is not a development blocker. No final QR has been generated. Generate it only after deployment and receipt of the actual public HTTPS booking URL. Localhost, private IP addresses, the reference website and sample deployment domains must not be used as substitutes.

Set `bookingUrl` in `config/public-registration.json` to the actual deployed root booking URL, then run `npm run qr:registration`. The generator can also read a real `FRONTEND_ORIGIN` from the backend environment configuration.

After successful generation this directory will contain:

- `santa-social-public-registration.png`: 2400 × 2400 pixels, white background, black modules, four-module quiet zone and high error correction.
- `santa-social-public-registration.svg`: scalable vector version of the same public URL and QR matrix.
- `verification.json`: decoded PNG and SVG destinations, image settings and artifact checksums.

Generation validates a public HTTPS hostname, resolves its addresses, checks the booking page is reachable, and independently decodes both rendered outputs before writing final artifacts. The single shared public code opens the booking form; it does not create a booking, approve payment, or grant admission. The separate group admission QR generated by the existing booking system is unchanged.
